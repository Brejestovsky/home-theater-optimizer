# Home Theater Setup Optimizer

**Geometric & Directional Acoustic Setup Optimization — v1.2.1**

Интерактивный инструмент, который по размерам комнаты и выбранной конфигурации
акустической системы (2.0 / 5.1 / 7.1 / Dolby Atmos 5.1.2) предлагает расстановку
колонок: позицию, угол, ориентацию (toe-in) и приблизительную мощность усилителя —
и визуализирует, насколько хорошо эта расстановка "накрывает" зону прослушивания.

Это ранний прототип. Он проверяет саму идею: превратить типовые рекомендации
Dolby/THX по расстановке в интерактивный, объясняемый расчёт, а не просто выдать
готовую цифру.

## Честно о том, что это (и что не это)

Программа считает **геометрию и условную направленность**, а не полную физику звука
в помещении. Она **не моделирует**:

- отражения от стен, потолка и пола;
- поглощение материалами (ковры, шторы, мебель);
- дифракцию и интерференцию;
- резонансные моды помещения.

Поэтому в интерфейсе она называется именно так — *Geometric & Acoustic Setup
Optimization*, а не *Acoustic Field Optimization*. Второе — цель следующего,
гораздо более сложного этапа, когда в расчёт добавится физическая модель
акустического поля.

## Что уже умеет

- **Геометрия комнаты** — ширина, длина, высота потолка.
- **4 типовые конфигурации**: Стерео 2.0, 5.1, 7.1, Dolby Atmos 5.1.2.
- **Зона прослушивания** вместо одной точки — ширина дивана, 3 точки сэмплирования
  (левый край / центр / правый край).
- **Перетаскивание** места прослушивания и каждой колонки прямо на плане.
- **Конусы направленности** — условная зона покрытия каждой колонки (шире у
  surround/rear, уже у фронтальных).
- **Ручной разворот (toe-in)** колонки независимо от её позиции — кнопками ±5°,
  со сбросом на автонаведение.
- **Закрепление позиции** — если колонку физически некуда поставить (например,
  там окно), её можно перетащить в доступное место и закрепить: оптимизатор
  больше её не тронет, но пересчитает всё вокруг.
- **Многофакторный Acoustic Score** вместо одного магического числа:
  - **Geometry** (25%) — совпадение позиции и наведения со стандартом
  - **Coverage** (25%) — доля точек зоны прослушивания, реально попадающих в
    конус направленности каждой колонки
  - **SPL Proxy** (20%) — дистанционная аппроксимация (не физический расчёт SPL)
  - **Distance** (20%) — равномерность расстояний между каналами
  - **Symmetry** (10%) — симметрия зеркальных пар каналов (L/R, LS/RS и т.д.)
- **Оптимизатор** — локальный стохастический поиск, который двигает незакреплённые
  колонки, чтобы максимизировать общий Score.
- **Приблизительный расчёт мощности** усилителя по объёму помещения.
- **3D-вид** (псевдо-3D, чистый SVG с перспективной проекцией, без WebGL) — тот же
  геометрический расчёт, показанный как комната с стенами, объёмными колонками и
  слоистыми конусами направленности. **Только просмотр** — перетаскивание работает
  в 2D-схеме (инверсия перспективной проекции для drag — в планах).

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Дорожная карта

**Ближайшее:**
- Перетаскивание объектов прямо в 3D-виде (нужна корректная инверсия перспективной
  проекции с учётом высоты каждого объекта).
- Явные зоны-исключения на плане (нарисовать "здесь окно/дверь"), а не только
  ручной drag + lock.
- Комнаты произвольной формы, не только прямоугольник.
- Плавное (не бинарное) затухание Coverage к краю луча направленности.

**Дальше:**
- Сканирование помещения камерой смартфона (AR) вместо ручного ввода размеров.
- Переход к физической модели акустического поля (отражения, поглощение,
  моды помещения) — тогда и переименование в *Acoustic Field Optimization*.
- Экспорт/сохранение расстановки, история версий.
